# Laboratorio Químico

Sitio web informativo desarrollado como parte del curso de **Desarrollo Web**.  
El proyecto busca representar un **laboratorio químico**, mostrando su identidad, servicios y medios de contacto en un entorno digital moderno y responsivo.

---

## Características principales

- **Página de inicio** con presentación del laboratorio.
- **Navbar y Footer responsivos** con Bootstrap.
- **Sección "Nosotros"** con información de la empresa.
- **Sección de servicios/productos** presentada con **cards**.
- **Formulario de contacto** para consultas.
- **Diseño adaptativo** para distintos dispositivos (desktop, tablet, mobile).

---

## Tecnologías utilizadas

- **HTML5** para la estructura semántica.
- **CSS3** para estilos personalizados.
- **Bootstrap 5.3.8 (CDN)** para diseño responsive y componentes.
- **Sass (opcional)** para la gestión de estilos escalables.
